# `stdx.arch.x86_64`

Port I/O, model-specific registers, interrupt control, fences, and cache maintenance.
Names below are relative to `stdx.arch.x86_64`.

## Target and faults

`supported` is true for x86_64 targets. Value types are usable on other targets.
Referencing an instruction wrapper on another target produces a compile error.

Callers MUST satisfy instruction feature, privilege, and memory-access requirements.
Hardware faults propagate to the caller's exception handling.
Operations perform no allocation or scheduler waiting.

## Port I/O

`io.Port` is a non-exhaustive `enum(u16)`. `io.Port.from()` and `io.Port.raw()`
preserve all 16-bit values.

| Operation | Contract |
| --- | --- |
| `io.Port.in8()` / `io.Port.in16()` / `io.Port.in32()` | Reads one value from the port at the selected width. |
| `io.Port.out8()` / `io.Port.out16()` / `io.Port.out32()` | Writes one value to the port at the selected width. |
| `io.Port.inSlice8()` / `io.Port.inSlice16()` / `io.Port.inSlice32()` | Reads sequentially into the supplied slice with `rep ins*`. |
| `io.Port.outSlice8()` / `io.Port.outSlice16()` / `io.Port.outSlice32()` | Writes the supplied slice sequentially with `rep outs*`. |
| `io.wait()` | Writes zero to port `0x80`. The delay is platform-dependent. |

Port access requires CPL <= IOPL or permission through the TSS I/O bitmap.
Denied access can raise `#GP`. Slice operations require DF = 0 and accessible
memory throughout the call. Callers serialize device accesses as required.
Wrappers include compiler memory clobbers. Work is O(1) for scalar transfers
and O(slice length) for slice transfers, excluding device latency.

## Model-specific registers

`msr.MSR` is a non-exhaustive `enum(u32)`. `msr.MSR.from()` and `msr.MSR.raw()`
preserve all register numbers. Named architectural identifiers are defined in
the [MSR declarations](../../../src/arch/x86_64/msr.zig).

`msr.read(register)` reads a `u64`. `msr.write(register, value)` writes one.
Both require CPL 0 and include compiler memory clobbers. Unsupported register
numbers and invalid writes can raise `#GP`. Callers check CPU capabilities,
preserve reserved bits, and follow each register's programming sequence.

## Interrupts and privilege

`irq.Vector` is a non-exhaustive `enum(u8)` containing architectural exception
numbers. `irq.Vector.from()` and `irq.Vector.raw()` preserve every vector value.

| Operation | Contract |
| --- | --- |
| `irq.enable()` | Executes `sti`. Requires CPL 0. An IF transition from 0 to 1 establishes the architectural one-instruction interrupt shadow. |
| `irq.disable()` | Executes `cli`. Requires CPL 0. |
| `irq.enabled()` | Reads RFLAGS.IF. |
| `privilege.currentLevel()` | Returns CS.RPL as a `u2` CPL value. |

Interrupt enable/disable include compiler memory clobbers.
Callers manage nesting, interrupt-controller state, and preemption.

## Fences

`fence.lfence()`, `fence.sfence()`, and `fence.mfence()` execute their
architectural fences and include compiler memory clobbers.
Use [barrier APIs](../barrier.md) for generic compiler, MMIO, and DMA ordering.

## Cache maintenance

| Operation | Requirements and effects |
| --- | --- |
| `cache.lineSize()` | Requires CLFLUSH and a nonzero power-of-two advertised line size. Returns CPUID leaf 1 EBX[15:8] multiplied by 8. |
| `cache.flush(address)` | CLFLUSH: writes back and invalidates the containing line. |
| `cache.flushOptimized(address)` | CLFLUSHOPT: optimized writeback and invalidation of the containing line. |
| `cache.writeBack(address)` | CLWB: writes back the containing line. |
| `cache.flushRange(ptr, len)` | Flushes every line intersecting `[ptr, ptr + len)`. Requires CLFLUSH for nonempty ranges. |
| `cache.writeBackRange(ptr, len)` | Writes back every intersecting line. Requires CLWB and CLFLUSH for nonempty ranges. |
| `cache.writeBackInvalidate()` | CPL 0: executes `wbinvd`. |
| `cache.invalidate()` | CPL 0: executes `invd`, discarding dirty cache data without writeback. |

Line operations require accessible addresses. Range ends MUST fit `usize`.
Empty ranges perform no cache operation. Unsupported instructions can raise
`#UD`. Privilege violations can raise `#GP`. Cache wrappers include compiler
memory clobbers. Callers provide ordering, completion, and persistence
protocols and synchronize access to affected storage.
Range work is O(intersecting lines). Other wrappers emit O(1) instructions.
Hardware completion latency depends on the operation and system.
